Про ZooFeed

ZooFeed — демо-інтернет-магазин кормів для тварин.

Для кого магазин?

Для власників собак, котів, птахів та гризунів, які хочуть швидко підібрати якісний корм.

Що всередині демо?

Каталог товарів, кошик, обране, порівняння, відгуки, базова авторизація та форма контактів.

Навіщо це все?

Щоб попрактикуватися у верстці, JavaScript та роботі з localStorage у реалістичному проєкті.

Відгуки покупців

Для спрощення демо ми показуємо кілька історій від покупців, а також даємо змогу додати свій відгук.
